# 体验课报名页 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 PRD 构建一个单链接、无后端、可本地打开的体验课报名 H5 页面（海报页 + 3 个详情页 + 报名页 + 结果页）。

**Architecture:** 纯静态 HTML/CSS/JS，无框架、无构建。`index.html` 内含全部视图，用 hash 路由切换；纯逻辑（校验 / 倒计时 / 表单状态）拆成独立 JS 文件，浏览器挂到 `window.App`、Node 用 `module.exports` 双端可用，用 Node 内置测试跑单测；DOM 交互集中在 `app.js`，视觉与交互在浏览器里手工验收。

**Tech Stack:** HTML5 + CSS3（原生）+ 原生 JavaScript（classic script，非 ES module）+ Node 24 内置 `node --test`（零 npm 依赖）。

**Spec:** `PRD.md`（项目根目录，同仓库）

## Global Constraints

- 单链接、页内 hash 路由；无后端、无网络请求、无外部 CDN，双击 `index.html`（`file://`）即可打开。
- 手机号校验正则 `^1[3-9]\d{9}$`；占位符 `12345678910`；错误文案 `请填写正确手机号`。
- 验证码为 4 位数字 `^\d{4}$`；本次不真正发送短信，倒计时 60 秒，按钮文字 `请${s}s后重试`（秒数递减）。
- 年级选项 19 项、课程选项 11 项（值见 PRD 5.1，以 `data.js` 为准并由测试固定）。
- 结果页红字：`信息已收到，报名结果将在24h内通过电话或短信通知`；详情页占位：`内容待更新`；视频占位：`往期家长或学生的视频`；老师照片占位：`图片`。
- 按钮文案：`立即报名` / `正在提交…` / `发送验证码`。
- 色板（PRD 7.1）：主蓝 `#2B5BE0`、深蓝 `#0A3DA6`、浅蓝描边/图标底 `#B6CCEA`、卡片底 `#F2F8FB`、正文 `#3A3540`、次要文字 `#8A8F99`、警示红 `#E5484D`、页面底 `#FFFFFF`。
- 每个任务结束都要 `git commit`（提交信息见各任务）。

## Review Focus

1. 手机号带空格 / 10 位 / 12 位 / 第二位是 0–2 / 含字母 → 必须判非法并提示 `请填写正确手机号`。→ Task 2 单测 + Task 8 手工。
2. 验证码非 4 位数字（字母 / 3 位 / 5 位）→ “立即报名”保持禁用。→ Task 2 单测 + Task 8 手工。
3. 删光所有家长或所有孩子 → 页面不报错、提交保持禁用。→ Task 4 单测 + Task 8 手工。
4. 手机号非法时点“发送验证码” → 不启动倒计时，仅显示手机号错误。→ Task 8 手工（先 `isValidPhone` 再启动倒计时）。
5. 快速连点“立即报名”或“发送验证码” → 只触发一次（禁用态兜底）。→ Task 8 / Task 9 手工。
