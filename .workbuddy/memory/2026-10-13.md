## 工具链：截图发白的假阳性（重要，别再踩）
`css/styles.css` 里 `.view.active { animation: fadeIn 0.28s ease; }`，`fadeIn` 从 `opacity: 0` 走到 `1`。
**无头 Edge 默认在动画中途就截图**，整页被均匀蒙一层白 —— 表现为「颜色全被冲淡、最暗像素只有 (171,184,197)、强蓝像素 0 个」，看起来像样式被压白，其实是假阳性。

**定式**：截图必须加 `--virtual-time-budget=2500`（或 3000）让动画跑完再抓。
```bash
"/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --headless=new --disable-gpu \
  --hide-scrollbars --virtual-time-budget=2500 --window-size=459,820 \
  --screenshot="out.png" "file:///.../page.html"
```
- 定位手法：先用一个只有色块的 `_probe.html` 隔离验证（色块能出正确色值 → 说明问题在页面而非渲染器）；再逐页统计「强蓝像素数 / 最暗像素」，量化的比肉眼看靠谱。
- 加 `--force-device-scale-factor=2/3` 可以看 2x/3x 细节，但**不影响**这个动画问题。
