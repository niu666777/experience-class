## 体验课报名页 · 第三轮：按素材一/二的语法重排版式

用户否掉第二轮结果：**「不要一块图片一块文字，要像素材一素材二一样的风格，图文相互映衬，风格和素材一二也不一样，说了必须严格参考」** —— 即"课程特色卡片底部塞一整张插画"这种堆叠式排版是错的。

先把 `素材一.jpg` / `素材二.jpg` 整图重新读了一遍，抽出两套版式语法：
- **素材一** = 白纸页面 + 左边缘线圈装订 + 蓝色手绘标签框（带回形针）+ 超大蓝色手写标题（吉祥物叠压在标题右侧）+ 蓝色缎带横幅 + 卡片左上角跨骑边框的蓝色标签 + ★/☑ 清单 + 蓝墨线涂鸦。
- **素材二** = 浅底 + 蓝色涂鸦，红黑双色大标题，**内容块左右交替（图-文 / 文-图）**，蓝色圆角描边的插画框，蓝色勾选胶囊标签。

按这两套语法重写：
- 首屏去掉蓝色渐变面板，改成**无边框白色纸页**（`#app` 网格底上浮着的白纸），加左侧 `.binding` 线圈（内联 SVG，`preserveAspectRatio="none"` 纵向撑满）、`.hero-label` 蓝底标签框 + 回形针 SVG、两行蓝色手写标题（两行反向旋转做手写堆叠）、`.hero-art` 负 margin 叠压标题右侧、`.hero-ribbon` 蓝色缎带（两端 `clip-path` 斜角）、涂鸦改成蓝墨色。
- `.module-title` 改成**跨骑卡片上边框**的标签，胶带移到右上角避让。
- `.feature-item` 与 `.teacher-card` 改成左右并排 + `:nth-child(even)` 镜像 → 真正的图文交替。`.teacher-top` 用 `display:contents` 让照片脱出包裹层参与 grid。
- `.detail-head` 由蓝色渐变条改成白纸 + 蓝墨描边。
- 底部行动条文案改成素材一/二的「点击【立即报名】领取 0 元体验课」句式，通栏深色、蓝色按钮、手绘指示手。

## 体验课报名页 · 第四轮：改成「2D 扁平彩铅手账风 + 马卡龙配色」

用户给了一整份竖版小红书招生海报的排版/风格提示词，要求"改变画风和页面"。落地为：

- **纸面**：方格纸 → **米白练习本横线内页**（`--paper #FCFAF4` + 30px 一行浅蓝横线）。
- **配色马卡龙柔化**：`--blue #2F6BFF → #4E8DE8`，`--blue-deep #0E2A6E → #1B3C74`，`--ink-line #8FB6F2 → #A8C8F0`；底部行动条底色也换成深蓝 `#1B3C74`。暖橙/黄/蓝绿只做点缀。
- **字体**：先做了字体试样截图对比（本机装了方正舒体/华文琥珀/华文行楷/幼圆/微软雅黑），最终定 **标题 = 方正舒体**（本身偏细，用 `-webkit-text-stroke` 同色描边加粗成"粗犷手写涂鸦"）、**正文 = 幼圆**。均为系统字体，新增 `--font-hand` / `--font-round` 两个变量。
- **彩铅颗粒**：`body::before` 铺 `feTurbulence` 噪点。
- **首屏**：白纸 → 浅蓝渐变 + 三处白色径向高光的"蓝天白云"；涂鸦从 6 个扩到 8 个并新增纸飞机、叶片，全部改成只贴四边。
- **✅ 项目符号**：详情页 `.feat-points li` / `.detail-teacher-section li` 改成蓝色勾选方框。

**两个必须记住的坑：**
1. `mix-blend-mode: multiply` 叠在 `position: fixed` 全屏层上，headless Edge 会把噪点渲染成**整屏同心圆环**（做对照实验定位到的：关掉噪点层 / 关掉混合模式都正常）。改成纯 alpha 叠加即好。
2. `.module-title` 白字 + `-webkit-text-stroke: 0.8px var(--blue)`（同色）→ 描边把细字形的内部整个填掉，**标题文字完全消失**。白字加粗只能用 `text-shadow: ±0.7px 0 0 #FFF`。

**没有重新生成插画**：提示词里对插画的要求是「Q 版圆润亚洲大人与学生、线条柔和、2D 平面无复杂光影、干净清晰轮廓线」，硬约束还明确禁止厚涂/写实 —— 现有 4 张扁平矢量卡通插画本来就符合，"蜡笔质感"落在手绘边框、手写字体和纸面颗粒上即可，避免不必要的额度消耗。

验证：`npm test` 50/50 通过；窄屏 375px / 桌面 1400px、首屏 / 特色 / 师资 / 成果 / 详情页 / 底部行动条全部截图核对。`PRD.md` §7 同步升到 v3。
